# foc — 无刷电机 FOC 控制库（BLDC / PMSM）

> 面向**汽车电子电机控制器**方向的嵌入式软件：把三相逆变器、SVPWM、Clarke/Park 变换、
> 电流环/速度环 PI（含前馈解耦与弱磁）、霍尔/编码器位置估算、BLDC 六步换相做成**可测可仿真的 C 库**。
>
> 纯 **C99**，零第三方依赖（数学函数来自 libm）。

## 1. 为什么做这个

电机控制器岗位的核心不是"会调库"，而是**能把控制环讲清楚、能算、能测**：

| 岗位关注点 | 本项目的对应实现 |
|---|---|
| 三相逆变器工作原理 | `InverterState` 上下桥互补驱动 + **死区** + **直通保护** |
| SVPWM | 扇区判定（不用 atan2）、T1/T2 计算、**过调制限幅**、母线为 0 退化处理 |
| Clarke / Park | 等幅值变换与逆变换，**往返一致性**有单测 |
| PID + 前馈 | 增量式 PI + **条件积分抗饱和** + **前馈解耦**（ωe·L·i 与反电动势） |
| 弱磁扩速 | 超基速后给负 id，并有对比场景 |
| BLDC / PMSM | 凸极/表贴两套参数；**六步换相表**与 FOC 两条技术路线都在 |
| 位置与速度 | **霍尔 120° 换相**（含无效状态识别）+ 编码器差分测速 + 低通 |
| 代码基本功 | 结构体收口状态、**union 双视图**（霍尔位域 / 桥臂位域）、指针传参无全局态 |

## 2. 快速开始

```bash
make test        # 96 项单元测试
make sim         # 跑 pmsm / bldc / ff / fw 四个场景
# 手动：
gcc -std=c99 -O2 -Wall -Wextra -Iinclude \
    src/foc_math.c src/foc_ctrl.c test/test_foc.c -o build/foctest -lm && ./build/foctest
./build/focsim pmsm      # 表贴式 PMSM：启动→加速→加负载
./build/focsim bldc      # 凸极 BLDC 参数 + 六步换相表
./build/focsim ff        # 有/无前馈解耦对比
./build/focsim fw        # 有/无弱磁扩速对比
```

## 4. 控制结构

```
速度参考 ω*
   │
   ▼
[速度环 PI] ──► iq*        id* = 0（表贴式 PMSM 的最优转矩/电流比）
   │
   ▼
[电流环 PI] (id, iq 各一个)  ──►  ud*, uq*
   │                                   ▲
   │         前馈解耦：ud_ff = -ωe·Lq·iq
   │                   uq_ff = +ωe·(Ld·id + ψf)（反电动势）
   ▼
[电压限幅] ──► [SVPWM] ──► 三相占空比 ──► [三相逆变器 + 死区] ──► 电机
   ▲                                                              │
   └────────── 霍尔 / 编码器：θe, ωm ◄───────────────────────────┘
```

## 5. 实测结果

### 单元测试

```
==== 结果：96 passed, 0 failed ====
```

覆盖：Clarke/Park 往返与幅值关系 · 电角度归一化 · PI 的比例/积分/限幅/**抗饱和**/前馈/复位 ·
SVPWM 四轴向扇区判定、T1+T2+T0=1、线电压和为 0、**过调制限幅**、母线 0V 退化 ·
霍尔六状态有效性与 60° 间隔、**000/111 判无效**、编码器角度/速度/低通 ·
六步换相三相职责互斥与轮转 · 桥臂互补与**直通注入检测** · 闭环收敛与 id=0 ·
弱磁分段与限幅 · 统计增量均值与效率口径

### 场景一：表贴式 PMSM（id=0 控制）

```
转速 301.16 / 300.00 rad/s（稳态误差 +0.39%）
iq均值 0.406 A   id均值 -0.014 A（≈0，符合 id=0 控制）
转矩均值 0.0426 N·m   相电流 RMS 0.667/0.989/0.852 A
效率≈99.0%（dq 轴口径，估算）   桥臂直通 0 次
```

### 场景二：**前馈解耦对比**（同一目标转速 450 rad/s）

| 配置 | 稳态转速 | 稳态误差 | 转矩脉动 |
|---|---|---|---|
| **有解耦** | 393.7 rad/s | **-12.5%** | 0.104 |
| 无解耦 | 221.4 rad/s | **-72.3%** | 0.405 |

高转速下反电动势与交叉耦合项会吃掉大部分电压，**不做前馈解耦时电流环几乎失去控制能力**。

### 场景三：**弱磁扩速对比**（目标 460 rad/s，基速 320）

| 配置 | 稳态转速 | 稳态误差 | id 均值 |
|---|---|---|---|
| **有弱磁** | **459.5 rad/s** | **-0.12%** | -7.97 A（负 id 削弱磁链） |
| 无弱磁 | 393.7 rad/s | -14.4% | -0.05 A |

超过基速后母线电压不足以维持电流环，必须靠弱磁才能继续升速（代价是同样转矩需要更大电流）。

## 6. 开发过程中踩到并修掉的问题

| # | 问题 | 现象 | 根因与修复 |
|---|---|---|---|
| 1 | **桥臂直通误报 5999 次** | 每次仿真都报直通 | 把"占空比在 (0,1) 区间"当成上下桥同时导通：`ah=(ta>0)`、`al=(ta<1)` 对 0<ta<1 同时为 1。实际三相桥上下管**互补**，任何瞬时只有一个导通。改为按 0.5 判定并取反；直通保护保留，由单测显式注入验证 |
| 2 | **转速只能到 197/300** | 稳态误差 -34% | 不是控制问题：24 V 母线、ψf=0.0175 Wb、P=4 时反电动势在 ωm≈188 rad/s 就顶到电压极限 `Udc/√3·0.95`。**参数选取错误**，母线改为 48 V |
| 3 | **效率算出 179%（非物理）** | 控制失效场景下 P_out > P_in | dq 轴功率口径 `1.5(ud·id+uq·iq)` 在电流脉动很大时失真。截断到 [0,1]，并在 README 明确标注这是**估算口径**（不计铁损/开关损耗/死区损失） |
| 4 | **报告里 iq ≈ 0 与转矩均值自相矛盾** | 末点 iq=-0.042 但转矩均值 0.0426 | 报告取的是**最后一个采样点**，正好落在转矩脉动谷底。改为报告统计期均值 |

> 另有 **4 处是测试预期写错**（PI 首次输出我以为不积分、SVPWM 扇区把 +β 轴写成扇区 3、
> 用末点 Te 精确比对负载、把扇区边界 0° 当成唯一答案），都逐一核对后**改测试而不是改正确的实现**。

## 7. 边界说明（重要）

- 本项目是**仿真与自建实践**，**未在真实电机与逆变器上运行过**，不构成产品/量产经验
- **电机模型是理想化的**：线性电感、无铁损、无磁饱和、无齿槽转矩、温度不参与；
  反电动势按正弦处理（BLDC 实际为梯形波）
- **未实现**：电流采样与 ADC 时序对齐、SVPWM 死区补偿、参数辨识（Rs/Ld/Lq/ψf 在线辨识）、
  无位置传感器控制（滑模/龙伯格观测器 + 反电动势过零）、MTPA/弱磁的最优点求解、
  CAN 标定与故障诊断（UDS/OBD）
- **未对接任何 MCU 外设**：没有 ADC/PWM/定时器的寄存器操作，是纯算法库 + 仿真
- 效率、温升等结论只来自仿真，不代表实测

**下一步可做**：接真实 MCU 的 ADC/PWM 驱动层；加反电动势过零的无感启动；
实现梯形波 BLDC 模型并与正弦 FOC 对比转矩脉动；加 CAN 标定接口。
